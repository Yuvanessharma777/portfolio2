YUVANESH SHARMA S — PORTFOLIO

FILES
- index.html: Home page
- projects.html: Projects, skills, and contact page
- style.css: Styling for the home page
- script.js: Home page interactions
- image/yuvanesh.jpg: Your profile photo

RUN LOCALLY
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Keep the image folder and all files in their current locations.

PUBLISHING
- Your profile photo is already connected on the home page.
- Project cards on the home page link to the Netlify websites configured in index.html.
- Replace placeholder GitHub links in projects.html with your real project URLs before publishing.
- The contact form requires your email address to be configured in script.js.
- Deploy the extracted folder to Netlify when you're ready.
